🛡️ Honeypot & Server Security Lab

Summary

Deployed a Windows OpenSSH honeypot to observe attacker behavior, analyze logs, and harden the system using firewall rules and monitoring techniques.

Tools Used

  • Windows OpenSSH
  • Windows Firewall
  • Event Viewer
  • PowerShell

Objectives

  • Deploy a functional SSH honeypot
  • Capture and analyze unauthorized login attempts
  • Implement system hardening techniques

Process

  • Installed and configured Windows OpenSSH
  • Monitored logs for brute‑force attempts
  • Blocked malicious IPs using firewall rules
  • Documented attacker patterns and behavior

Findings

Observed repeated brute‑force attempts from automated bots targeting common usernames. Firewall rules successfully mitigated repeated attacks.

What I Learned

Gained hands‑on experience with SSH security, log analysis, and defensive hardening techniques.
