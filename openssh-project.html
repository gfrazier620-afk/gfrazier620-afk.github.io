⚙️ Windows OpenSSH Hardening

Summary

Configured and secured a Windows OpenSSH server by applying hardening techniques, monitoring logs, and implementing firewall rules to reduce attack surface.

Tools Used

  • Windows OpenSSH
  • Windows Firewall
  • PowerShell
  • Event Viewer

Objectives

  • Secure an SSH service on Windows
  • Reduce unauthorized access attempts
  • Monitor and analyze SSH logs

Process

  • Installed and configured OpenSSH server
  • Disabled password authentication and enforced key‑based login
  • Restricted SSH access to specific IP ranges
  • Monitored logs for suspicious activity

Results

Successfully reduced brute‑force attempts and improved overall security posture through layered hardening techniques.

What I Learned

Gained practical experience in SSH security, Windows server hardening, and log‑based threat detection.
