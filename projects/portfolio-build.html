Cybersecurity Portfolio Build

A fully custom SOC‑themed portfolio built from scratch using HTML, CSS, and GitHub Pages.

Overview

This project documents the full build of my cybersecurity portfolio — a tactical, dark‑themed, SOC‑inspired website designed to showcase my labs, projects, resume, and cybersecurity journey. The site was built entirely from scratch using HTML, CSS, and JavaScript, with a focus on clean UI, responsive design, and a professional SOC analyst aesthetic.

Objectives

  • Create a professional cybersecurity portfolio from scratch.
  • Design a tactical SOC‑themed UI with dark mode and neon accents.
  • Showcase hands‑on labs, projects, and cybersecurity skills.
  • Implement responsive layouts and smooth navigation.
  • Deploy the site using GitHub Pages.

Tools Used

  • HTML5 / CSS3 / JavaScript
  • GitHub & GitHub Pages
  • VS Code
  • Linux & Windows testing environments
  • Custom UI/UX design

Build Process

  • Designed the site layout and tactical theme.
  • Built the homepage hero, navbar, and section structure.
  • Created a full Labs section with 16 cybersecurity labs.
  • Developed a Projects section with detailed project pages.
  • Added animations, hover effects, and responsive styling.
  • Integrated GitHub, LinkedIn, and resume links.
  • Deployed the site using GitHub Pages.

Challenges

  • Ensuring consistent styling across 20+ pages.
  • Building a clean, responsive layout without frameworks.
  • Managing folder structure for labs, projects, and assets.
  • Creating a cohesive SOC‑themed design without clutter.

What I Learned

  • Advanced CSS layout techniques (grid, flexbox, responsive scaling).
  • How to structure a multi‑page website cleanly.
  • Version control and GitHub workflow best practices.
  • How to design a professional cybersecurity‑focused UI.
  • How to document labs and projects clearly and professionally.
