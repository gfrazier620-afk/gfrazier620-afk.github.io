Wireshark Lab

Capture and analyze network traffic to identify suspicious activity.

Objective

Use Wireshark to capture packets, filter traffic, and identify anomalies.

Tools Used

  • Wireshark
  • Sample PCAP files

Steps

  • Start a packet capture.
  • Filter HTTP traffic:
    http
  • Filter DNS traffic:
    dns
  • Identify a TCP 3‑way handshake.
  • Locate suspicious traffic (strange ports, odd DNS queries).

Summary

This lab builds packet analysis skills essential for SOC investigations.
