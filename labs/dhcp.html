DNS Lab

Investigate DNS queries, records, and common attack vectors.

Objective

Understand how DNS works by querying records and analyzing DNS traffic.

Tools Used

  • nslookup / dig
  • Wireshark

Steps

  • Run nslookup google.com and review the response.
  • Query A, AAAA, MX, TXT, and NS records.
  • Capture DNS traffic in Wireshark.
  • Identify DNS request/response patterns.
  • Review signs of DNS tunneling or exfiltration.

Summary

This lab builds DNS fundamentals and teaches how attackers abuse DNS channels.
