Microsoft Sentinel Lab

Build detections, analyze incidents, and use KQL queries.

Objective

Use Microsoft Sentinel to analyze alerts, run KQL queries, and simulate SOC investigations.

Tools Used

  • Microsoft Sentinel
  • Log Analytics Workspace
  • KQL Query Editor

Steps

  • Open Sentinel → Logs.
  • Run a basic KQL query:
    SecurityEvent | take 20
  • Filter for failed logons:
    SecurityEvent | where EventID == 4625
  • Investigate an alert from the Incidents panel.
  • Document findings and recommended actions.

Summary

This lab builds real‑world SIEM investigation skills using Microsoft Sentinel.
