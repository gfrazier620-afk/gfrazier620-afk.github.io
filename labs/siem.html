SIEM Lab

Analyze logs, detect threats, and simulate SOC workflows.

Objective

Use a SIEM platform to ingest logs, identify suspicious activity, and simulate a real SOC investigation.

Tools Used

  • Splunk / Sentinel / Elastic (any SIEM)
  • Windows Event Logs
  • Sample attack logs

Steps

  • Ingest Windows Security logs into the SIEM.
  • Run searches for failed logons (Event ID 4625).
  • Identify brute‑force patterns using time‑based queries.
  • Correlate events with source IP addresses.
  • Create a detection rule for repeated failed logons.
  • Document findings and recommended actions.

Summary

This lab demonstrates how SIEM tools help analysts detect suspicious authentication activity and build detections.
