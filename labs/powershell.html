PowerShell Lab

Run system commands, gather logs, and automate tasks.

Objective

Use PowerShell to gather system information and automate basic security tasks.

Tools Used

  • Windows PowerShell
  • Event Log Cmdlets

Steps

  • List running processes:
    Get-Process
  • View failed logons:
    Get-EventLog -LogName Security -InstanceId 4625
  • Check network connections:
    Get-NetTCPConnection
  • Create a simple script to automate log collection.
  • Document findings.

Summary

This lab builds PowerShell fundamentals used in Windows security operations.
