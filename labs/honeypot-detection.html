Securing Servers Using Honeypots and IP Blocking Lab

Cybersecurity Portfolio – Garret Frazier

Overview

Configure a Windows OpenSSH honeypot, simulate an SSH connection attempt from Kali, detect and document evidence in logs, and mitigate the threat by blocking the attacker IP with a Windows Firewall rule.

Objectives

  • Configure an OpenSSH server on a Windows VM
  • Verify SSH connection from a Kali machine
  • Identify the breach in OpenSSH logs
  • Block the Kali IP via a firewall rule

Tools & Technologies

  • Windows VM with OpenSSH server
  • Kali Linux machine
  • Windows Firewall
