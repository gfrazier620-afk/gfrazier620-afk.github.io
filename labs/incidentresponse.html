Incident Response Concepts Lab

Walk through IR phases: preparation, detection, containment, and recovery.

Objective

Understand the NIST Incident Response lifecycle and simulate a basic IR workflow.

Tools Used

  • Sample incident report
  • Windows logs
  • Documentation templates

Steps

  • Review the NIST IR phases: Preparation, Detection, Containment, Eradication, Recovery, Lessons Learned.
  • Analyze a simulated security alert (failed logons, suspicious process, etc.).
  • Document the detection and initial triage.
  • Recommend containment actions (disable account, isolate host).
  • Write a short IR summary report.

Summary

This lab builds foundational IR knowledge and teaches how to structure an investigation.
