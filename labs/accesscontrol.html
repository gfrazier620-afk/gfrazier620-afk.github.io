Access Control Lab

Configure permissions, groups, and least‑privilege access models.

Objective

Understand access control concepts by configuring user permissions and enforcing least privilege.

Tools Used

  • Windows Local Users & Groups
  • Linux file permissions
  • Active Directory (optional)

Steps

  • Create a new user account.
  • Add the user to a specific group.
  • Modify folder permissions (Read, Write, Execute).
  • Test access before and after permission changes.
  • Document least‑privilege recommendations.

Summary

This lab builds foundational access control knowledge used in identity and security operations.
