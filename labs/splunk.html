Splunk Lab

Search, filter, and visualize log data using Splunk queries.

Objective

Use Splunk to search logs, identify anomalies, and build visualizations.

Tools Used

  • Splunk Enterprise / Splunk Free
  • Sample log dataset

Steps

  • Upload sample logs into Splunk.
  • Run a basic search: index=* error
  • Filter by source IP and event type.
  • Create a timechart visualization.
  • Build a dashboard panel.
  • Document findings.

Summary

This lab demonstrates Splunk search, filtering, and dashboard creation.
