Linux Commands Lab

Master essential Linux commands for SOC and sysadmin work.

Objective

Learn core Linux commands used in security operations, log analysis, and system administration.

Tools Used

  • Linux VM (Ubuntu, Kali, etc.)
  • Terminal

Steps

  • List files:
    ls -la
  • Check running processes:
    ps aux
  • Search logs:
    grep "error" /var/log/syslog
  • Check network connections:
    netstat -tulpn
  • View system info:
    uname -a

Summary

This lab builds Linux fundamentals essential for SOC analysts and system administrators.
