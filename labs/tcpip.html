TCP/IP Lab

Analyze packets, ports, and protocols used in network communication.

Objective

Understand how TCP/IP works by analyzing packet flow and identifying protocol behavior.

Tools Used

  • Wireshark
  • Command line tools (ping, tracert, netstat)

Steps

  • Run ping google.com and observe ICMP packets.
  • Use tracert to map network hops.
  • Capture traffic in Wireshark and filter by protocol (TCP, UDP, ICMP).
  • Analyze a TCP 3‑way handshake.
  • Identify common ports (80, 443, 22, 53).

Summary

This lab builds core networking knowledge essential for SOC investigations.
