Windows Event Viewer Lab

Investigate authentication events, system logs, and security alerts.

Objective

Use Windows Event Viewer to analyze authentication logs and identify suspicious activity.

Tools Used

  • Windows Event Viewer
  • Security, System, and Application logs

Steps

  • Open Event Viewer → Windows Logs → Security.
  • Locate Event ID 4624 (successful logon) and 4625 (failed logon).
  • Identify unusual logon types (Type 3, Type 10).
  • Check timestamps for repeated failures.
  • Document suspicious IPs or usernames.

Summary

This lab builds foundational skills in reading Windows logs and identifying authentication anomalies.
