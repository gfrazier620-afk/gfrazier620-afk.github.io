Network Analysis Lab

Tools: Wireshark, tcpdump

Objective

Analyze packet captures to identify suspicious traffic patterns and potential indicators of compromise.

Environment

  • Kali Linux VM
  • PCAP file with simulated malicious traffic

Key Steps

  • Loaded PCAP into Wireshark
  • Applied filters for DNS, HTTP, and suspicious traffic
  • Identified abnormal DNS queries

Findings

  • Detected beaconing behavior
  • Possible DNS tunneling
